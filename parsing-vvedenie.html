Парсинг: страница сайта → таблица

Парсинг — программа забирает страницу, находит в ней нужные куски и складывает их в таблицу.

Три шага, всегда одни и те же

  • Забрать страницу — библиотека requests
  • Разобрать её — библиотека BeautifulSoup
  • Сохранить в файл — библиотека pandas

Где пригодится

Цены конкурентов, вакансии, отзывы для обучения модели, статистика, свой Telegram-бот с данными.

Человек копирует 500 карточек за день. Скрипт — за пару минут.
Теория · 2 из 3 · коротко

Что можно парсить

Четыре правила

  • Берём только публичные данные: то, что видно без входа в аккаунт
  • Не собираем персональные данные людей
  • Не мучаем сайт: между запросами пауза time.sleep(0.3)
  • Заглядываем в сайт/robots.txt — там сайт сам пишет, куда роботам нельзя
User-agent: *        # для всех роботов
Disallow: /admin/    # сюда нельзя
Allow: /catalogue/   # сюда можно
Crawl-delay: 2       # пауза 2 секунды

Мы работаем на сайтах, созданных специально для тренировки: quotes.toscrape.com, books.toscrape.com, httpbin.org.

Сайт присылает обычный текст

  • Наш скрипт отправляет запрос по адресу
  • Сервер присылает ответ: код состояния и тело
  • Тело — это HTML: текст с тегами. Браузер по нему рисует страницу, а мы будем искать в нём данные
Запомнить одно: страница — это строка. Всё остальное сегодня — как удобно искать в этой строке.
Библиотека 1 · установка

Ставим requests

pip install requests pip — программа-установщик пакетов Python. install — команда «скачай и поставь». requests — имя пакета на сайте pypi.org, откуда pip его и скачивает.

Что именно происходит

  • pip идёт на pypi.org, скачивает архив пакета и кладёт его в папку Python
  • После этого в любом файле можно написать import requests
  • Ставим один раз на компьютер, а не при каждом запуске скрипта
  • В Colab и Jupyter то же самое пишут с восклицательным знаком: !pip install requests
Successfully installed requests-2.32.3 # проверяем, что встало: import requests print(requests.__version__) 2.32.3

Зачем нам этот пакет

requests умеет ровно то, что делает браузер, когда вы вводите адрес: сходить на сайт и принести ответ. Только без картинок и оформления — чистый текст.

Частые ошибки установки

  • pip install request — без s на конце поставится совсем другой пакет
  • ModuleNotFoundError: No module named 'requests' — пакет не поставлен или поставлен в другой Python
  • В Colab ставить обычно не нужно: requests уже есть
Правило: pip install — в терминале, import — в коде. Это разные вещи и делаются в разных местах.

Разбор

Минимальный рабочий вызов

r = requests.get("http://quotes.toscrape.com/")

Так тоже работает. Но без timeout скрипт может зависнуть навсегда, а без headers часть сайтов ответит отказом. Поэтому пишем полную форму.

Что такое r

r — это объект ответа. Внутри него лежит всё, что прислал сервер: код, заголовки и тело. Как коробка с посылкой — на следующем слайде её распакуем.

Проверка кода ответа

Разбор по строкам · нажимайте

Коды, которые встретятся

  • 200 — всё хорошо, страница пришла
  • 404 — такой страницы нет: проверьте адрес
  • 403 — сайт не пустил: чаще всего нужен User-Agent
  • 429 — слишком часто стучимся: увеличить паузу
  • 500 и выше — сломался сервер: подождать и повторить
https://httpbin.org/status/404 -> 404 | ok: False https://httpbin.org/status/403 -> 403 | ok: False

httpbin.org умеет отдавать любой код по запросу — на нём и потренируемся.

Библиотека 1 · headers и timeout

Как представиться сайту и не зависнуть

headers — визитка запроса

headers = {
    "User-Agent": "IThub-student-bot/1.0"
}
  • Словарь: слева название заголовка, справа значение
  • User-Agent — «кто я». Браузер пишет сюда своё название, а requests по умолчанию — python-requests/2.32.3, и часть сайтов на это отвечает 403
  • Только латиница: русские буквы в заголовке уронят запрос с UnicodeEncodeError
наш User-Agent дошёл до сервера: IThub-student-bot/1.0 (educational project)

timeout — сколько ждать

r = requests.get(url, headers=headers, timeout=10)
  • Число в секундах. Не ответили за 10 — скрипт бросит ошибку, а не будет ждать вечно
  • Без timeout зависший сайт остановит весь парсер

Ошибка сети — это исключение

try:
    r = requests.get(url, headers=headers, timeout=10)
except requests.RequestException as e:
    print("сеть подвела:", e)

RequestException — общий «родитель» всех ошибок библиотеки: нет интернета, не найден домен, вышел таймаут.

Библиотека 2 · установка

Ставим BeautifulSoup

pip install beautifulsoup4 lxml Две библиотеки сразу. beautifulsoup4 — сама библиотека разбора HTML (цифра 4 — версия, так называется пакет). lxml — быстрый движок, который читает HTML и строит из него дерево; BeautifulSoup пользуется им как мотором.

Имя пакета и имя для импорта разные

# ставим так:
pip install beautifulsoup4

# а импортируем так:
from bs4 import BeautifulSoup
  • bs4 — имя модуля внутри пакета
  • BeautifulSoup — класс, который мы вызываем
  • pip install bs4 — так делать не надо: это пакет-обёртка, в реальных проектах ставят beautifulsoup4

Зачем нужен lxml

HTML на настоящих сайтах часто сломан: незакрытые теги, лишние пробелы. Движок разбора это терпит и всё равно строит дерево.

  • "lxml" — быстрый, ставится отдельно
  • "html.parser" — встроен в Python, ставить нечего, но медленнее
Successfully installed beautifulsoup4-4.12.3 lxml-5.2.2 # проверяем: from bs4 import BeautifulSoup print(BeautifulSoup("<b>привет</b>", "lxml").text) привет
Библиотека 2 · что она вообще делает

Из длинной строки — в дерево, по которому можно ходить

Слева — то, что прислал сервер: одна длинная строка. Искать в ней данные вручную больно.

  • BeautifulSoup читает строку и строит дерево тегов
  • Каждый тег становится объектом: у него есть имя, атрибуты, текст и соседи
  • Теперь можно просто спросить: «дай первый тег с классом quote»
soup = BeautifulSoup(html, "lxml")
print(soup.title.text)
Вся библиотека — про одно: из текста сделать дерево и удобно по нему искать.

Чем find отличается от find_all

first = soup.find("div", class_="quote") print(type(first)) <class 'bs4.element.Tag'> # один тег all_q = soup.find_all("div", class_="quote") print(type(all_q), len(all_q)) <class 'bs4.element.ResultSet'> 10 # список

Библиотека 2 · как достать значение

.text берёт текст, .get берёт атрибут

Нажмите на тег в дереве

Что вернётся

  • .text — весь текст внутри тега, включая вложенные
  • .get("href") — значение атрибута; если атрибута нет, вернётся None
  • tag["href"] — то же самое, но упадёт с ошибкой, если атрибута нет
  • .strip() — убрать лишние пробелы и переносы по краям текста

Бонус · когда парсить не нужно

Если сайт отдаёт JSON — забираем его напрямую

ставить нечегоJSON умеет сам requests: метод r.json() превращает ответ сервера в обычный словарь Python. Модуль json встроен в Python и отдельно не ставится.
r = requests.get("https://dummyjson.com/products?limit=3",
                 timeout=10)
data = r.json()            # словарь, а не строка

print(list(data.keys()))   # какие ключи внутри
print(data["total"])       # сколько всего товаров
for p in data["products"]:
    print(p["title"], p["price"])
ключи ответа: ['products', 'total', 'skip', 'limit'] всего товаров: 194 Essence Mascara Lash Princess 9.99 Eyeshadow Palette with Mirror 19.99 Powder Canister 14.99
  • Данные приходят уже структурой: ни тегов, ни селекторов
  • Разметку сайта могут переделать за ночь — API меняют реже
  • Пагинация задаётся параметрами: ?limit=30&skip=60
  • Из списка словарей сразу получается таблица: pd.DataFrame(data["products"])

Как найти такой адрес

F12 → вкладка Network → фильтр Fetch/XHR → обновить страницу. Если в ответе видно JSON с нужными данными — берите этот адрес.

Порядок выбора всегда такой: сначала API, потом HTML, и только в крайнем случае браузер (Selenium, pip install selenium).
